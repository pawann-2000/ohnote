OhNote.

Open notebooks anywhere.

Right-click any Colab, GitHub .ipynb, raw, gist, or nbviewer link and pick a platform to open the notebook in.

Direct import

These build a launch URL straight to the platform.

    Manual import

    These platforms don't accept an import URL. OhNote will open their create page and copy the source URL so you can paste it.

      Recognized inputs

      • colab.research.google.com/github/USER/REPO/blob/BRANCH/PATH.ipynb
      • colab.research.google.com/gist/USER/GIST_ID
      • colab.research.google.com/drive/FILE_ID (Colab → Colab only)
      • github.com/USER/REPO/blob/BRANCH/PATH.ipynb
      • raw.githubusercontent.com/USER/REPO/BRANCH/PATH.ipynb
      • gist.github.com/USER/GIST_ID
      • nbviewer.org/github/...
      • Shortened links (t.co, bit.ly, tinyurl.com, …) pointing at any of the above
